# Контур - очистка персональных данных

Контур - учебное веб-приложение для подготовки фотографий и документов к передаче другим людям. Пользователь загружает файл, отмечает области с персональными данными и скачивает обработанную копию.

## Возможности

- Загрузка изображений JPG и PNG, а также документов PDF.
- Выбор файла через диалог или перетаскивание.
- Проверка типа файла и ограничения размера — до 20 МБ.
- Просмотр загруженного изображения.
- Ручное выделение прямоугольных областей для скрытия.
- Выбор категории области: лицо, автомобильный номер или телефон.
- Удаление выделенных областей.
- Предварительный просмотр результата.
- Скачивание PNG-копии с закрашенными областями.
- Просмотр PDF без редактирования.
- Демонстрационные формы входа, регистрации и личного кабинета.
- Адаптивный интерфейс и навигация между экранами.

Обработка изображений выполняется локально в браузере. Исходный файл не изменяется и не отправляется на сервер.

## Технологии и зависимости

### Frontend

- React — создание компонентов интерфейса и управление состоянием.
- TypeScript — типизация и проверка кода.
- React Router — клиентская маршрутизация.
- Material UI — готовые компоненты интерфейса.
- Material UI Icons — иконки.


## Настройка окружения

Для запуска необходимы:

- Node.js версии 20.19+ или 22.12+;
- npm;
- современный браузер.

Проверить установку Node.js и npm можно командами:

    node --version
    npm --version


## Установка и запуск

1. Скачайте проект или клонируйте репозиторий.
2. Откройте терминал в корневой папке `kontur-lab1`.
3. Установите зависимости:

       npm ci

4. Запустите сервер разработки:

       npm run dev

5. Откройте адрес, указанный в терминале. Обычно это:

       http://localhost:5173

Если порт занят, Vite может выбрать другой — используйте адрес из вывода команды.

Для остановки сервера нажмите `Ctrl + C` в терминале.

## Проверка и сборка

Создать готовую сборку:

    npm run build

Команда сначала выполняет проверку TypeScript, затем собирает приложение с помощью Vite. Результат сохраняется в папке `dist/`.

Запустить локальный просмотр собранной версии:

    npm run preview

Откройте адрес, который появится в терминале. После изменения исходников перед просмотром готовой версии необходимо повторить сборку.

## Экраны приложения

| Экран | Адрес | Назначение |
|---|---|---|
| Загрузка | `/` | Выбор файла и проверка его типа и размера |
| Проверка | `/review` | Просмотр файла, добавление и удаление масок |
| Экспорт | `/export` | Предпросмотр результата и скачивание PNG |
| Вход и регистрация | `/auth` | Демонстрационные формы авторизации |
| Личный кабинет | `/profile` | Данные текущей демонстрационной сессии |

Переходы выполняются средствами React Router без полной перезагрузки страницы.
